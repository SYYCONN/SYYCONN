# Olá, eu sou o Victor Siconato! 👋

### Estudante de Análise e Desenvolvimento de Sistemas

Sou estudante de tecnologia e estou construindo minha jornada no desenvolvimento de software. Gosto de aprender na prática, transformar exercícios em projetos e descobrir novas formas de resolver problemas com código.

Comecei desenvolvendo páginas e formulários com HTML, CSS e Bootstrap e, com o tempo, passei a explorar aplicações mais completas. Atualmente, venho praticando **desenvolvimento full stack**, utilizando React no frontend e Python com FastAPI no backend.

Um dos projetos que acompanha essa evolução é o **Sycon Suite**, um sistema de gestão empresarial modular no qual trabalho com recursos de estoque, finanças, funcionários, ordens de serviço e organização de empresas. Esse projeto tem me ajudado a entender melhor como as diferentes partes de uma aplicação se conectam.

### Sycon Suite

O **Sycon Suite** é meu projeto mais completo até aqui. Ele é um SaaS de gestão empresarial pensado para pequenas e médias empresas, reunindo módulos como estoque, finanças, funcionários, produção e ordens de serviço.

Durante o desenvolvimento, venho aprendendo sobre autenticação, permissões de usuários, organização de APIs, integração entre frontend e backend, banco de dados, responsividade e preparação de aplicações para produção.

Cada repositório representa uma etapa do meu aprendizado e mostra um pouco da minha evolução como desenvolvedor.
